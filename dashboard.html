REST API Endpoints Reference

POST /api/auth/signup

Registers a new user in MongoDB with hashed password (bcrypt).

{
  "name": "Jane Doe",
  "email": "jane@example.com",
  "password": "securePassword123"
}
POST /api/auth/login

Authenticates user and returns JWT Bearer token.

{
  "email": "jane@example.com", // or "fname": "Jane Doe"
  "password": "securePassword123"
}
GET /api/auth/users

Returns list of registered users (passwords omitted).

POST /api/queries

Submits customer query / feedback form to MongoDB.

{
  "name": "John Doe",
  "email": "john@example.com",
  "message": "When will new smart watches arrive?"
}
GET /api/products

Returns products. Filter via query params: ?category=mens or ?search=fastrack

POST /api/orders

Places order with items and saves to MongoDB collection.
